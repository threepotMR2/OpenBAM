# OpenBAM
Collection of open source CAD designs, ESP32 Firmware, wiring diagrams etc for installing a VW 1.8T 20v engine known as BAM into a Toyota MR2 Spyder zzw30 Mk3 Roadster

# Here you will find documentation for parts that are helpful in carrying out your 1.8T engine swap.

 - Engine Mounts
 - Drive Shafts (https://github.com/threepotMR2/OpenBAM/blob/main/Drive%20Shaft%20Blueprint%20Right%20662mm%20Left%20388mm.PDF)
 - Wiring information
 - CAN2BEAN electronics and esp32 firmware
 - 4wd rear right hand plate with seals
 - Exhaust fabrication
 - Coolant pipework
 - Fuel System
 - Charge Cooling System
 - K04 to V Band Downpipe adapter for 3D Print (https://github.com/threepotMR2/OpenBAM/tree/main/K04%20Exhaust%20Adapter)
